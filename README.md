# Equipo-Morado---Visor3D
Repositorio para organizar y entregar actividades de clase, prácticas y proyectos relacionados con el desarrollo de videojuegos.
Carpeta de figuras

Se creó una carpeta destinada a organizar y almacenar las figuras desarrolladas por los integrantes del equipo. Cada integrante realizó sus aportaciones de acuerdo con las actividades asignadas y trabajó de manera independiente en su propia rama de Git. Esto permitió mantener organizados los archivos, controlar las modificaciones realizadas y facilitar la colaboración e integración del trabajo dentro del repositorio principal.
